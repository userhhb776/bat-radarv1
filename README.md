# Lead Navigator Pro

Estou começando um negócio onde procuro leads (empresas locais) para prospectar e oferecer criação de site profissional e melhoria de posicionamento no Google Meu Negócio.

Crie uma plataforma completa de prospecção com:
1. Busca e filtros avançados de empresas por nicho (ex: clínicas, restaurantes, advogados), cidade/bairro, status de site (sem site cadastrado vs. com site), nota e volume de avaliações no Google Maps.
2. Listagem de leads com cards detalhados mostrando nome da empresa, telefone, endereço, nota, total de avaliações, presença de site e status de oportunidade.
3. Auditoria com IA: botão para analisar o perfil da empresa, identificando pontos fortes e principais gargalos (ex: sem site, fotos desatualizadas, poucas avaliações recentes, perda de clientes para concorrentes).
4. Gerador de abordagem personalizada persuasiva com IA focada em conversão (usando a fórmula: elogio específico + problema visível/oportunidade perdida + gancho de baixo atrito).
5. Botão direto para WhatsApp (wa.me) que abre a conversa com o número da empresa já com a mensagem personalizada pronta para envio.
6. Pipeline / Mini-CRM para salvar leads e gerenciar status (Novo, Mensagem Enviada, Respondeu, Reunião Agendada, Fechado, Perdido).
